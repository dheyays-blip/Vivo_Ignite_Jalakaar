# JALAAKAR — what the SERVER needs, and nothing else.
#
#     pip install -r requirements-deploy.txt
#
# requirements.txt + requirements-api.txt together install 1.3 GB, which is
# more disk than a small host wants to hand you and slower to build than it
# needs to be. Most of that weight never runs in production:
#
#   400 MB  nvidia-*        CUDA runtime, pulled in by the `xgboost` wheel.
#                           There is no GPU on any host we deploy to. It is
#                           downloaded, unpacked, and never once imported.
#   228 MB  xgboost         the GPU-enabled build the CUDA libs belong to
#    36 MB  matplotlib      charts, used by ml/ and reports/ — never by api/
#    28 MB  fontTools       matplotlib's dependency
#     7 MB  Pillow          matplotlib's dependency
#
# `xgboost-cpu` is the same library built without the GPU half. Verified
# against models/xgb_causal.json: both builds report
#     [model] loaded xgb_causal.json, 26 features, best_iteration=508
# and api.model.available() is True on both — the served forecast is the
# trained model, not the climatology fallback, so the published MAE holds.
#
# Result: 1.3 GB -> 533 MB, same numbers.
#
# This file is for DEPLOYING. To retrain, run ingest, or regenerate figures,
# use requirements.txt — that path still needs full xgboost and matplotlib.
